# ⚔️ 排兵布阵图 — 需求排期与人力容量演示工具

一款用于「需求排期 / 人力容量评估 / 路线图推演」的可视化演示工具。把需求按期次排开，结合产品、前端、后端、测试与全栈人力，实时计算容量、瓶颈、依赖冲突和完成日期，适合在评审会、规划会、内部分享中现场演示。

## ✨ 核心特性

- 🎯 **需求排期分配**：支持拖拽、点击加入当前期、下拉指定期，桌面和移动端都能完成排期。
- 🗓️ **多期规划**：支持多期次(Sprint / 月度 / 季度)切换,跨期推演长周期路线图。
- 🔗 **依赖追踪**：为需求维护前置依赖,自动识别阻塞关系并在视图中提示。
- 📊 **自动结论**:根据投入人力与剩余工作量,自动给出 **完成日期、容量缺口、瓶颈角色和调整建议**。
- 🎬 **一键演示**:内置演示模式,带旁白与视觉聚焦,适合现场讲解、录屏分享。
- 🎨 **6 套主题**:默认苹果毛玻璃,也可切换午夜商务、清爽极简、工地暖橙、科技仪表盘、柔和卡片。
- 💾 **数据本地持久化**:全部数据保存在浏览器 **localStorage**,支持 **JSON 导入 / 导出、本地备份、恢复和删除撤销**。
- 🖨️ **彩色打印排期**:打印时保持白底省墨,但保留容量条、优先级、复杂度、风险和依赖冲突的关键语义色。
- 📦 **纯单文件零依赖**:整个应用就是一个 `index.html`,内联所有 CSS / JS,**无构建、无安装、无后端**。

## 🚀 本地使用

最简单的方式:**直接用浏览器打开 `index.html`** 即可,无需任何构建或安装步骤。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

## 🐳 Docker 部署(可选)

若希望在内网或服务器上托管,可使用仓库自带的 `Dockerfile` 与 `docker-compose.yml`(基于 `nginx:alpine`):

```bash
docker compose up -d
```

启动后访问 **<http://localhost:8080>**(容器内 nginx 监听 80,默认映射到宿主机 **8080** 端口,可按需在 `docker-compose.yml` 中调整)。

停止与清理:

```bash
docker compose down
```

## 🛠️ 技术说明

- 单文件 HTML 应用,所有 CSS / JavaScript 均**内联**在 `index.html` 中。
- **无外部依赖**、**无构建步骤**、**无后端服务**,任意现代浏览器即可运行。
- Docker 镜像仅在 `nginx:alpine` 上拷贝一份 `index.html`,体积极小、启动迅速。

## ✅ 本地校验

仓库提供一个零依赖静态校验脚本,用于确认默认主题、彩色打印、本地备份、撤销删除、指定期下拉、可访问性标签等关键能力仍存在:

```bash
node verify-static.js
```

## 💾 数据说明

- 所有需求、兵卒、排期、主题等配置均保存在浏览器的 **localStorage** 中,刷新与重开浏览器后仍然保留。
- 数据**仅存储在本地**,不会上传到任何服务器。
- 通过界面上的「**导出**」按钮可将当前状态保存为 JSON 文件;「**导入**」按钮可从 JSON 文件恢复,便于备份、迁移或与他人共享方案。
- 如需重置,可在浏览器中清除该站点的 localStorage,或在界面中执行清空操作。
